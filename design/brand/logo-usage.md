# Buytiva logo use

The editable SVG source is in `apps/web/static/brand/`. The interwoven Ribbon Pulse mark has a blue leading path, coral counter-path and lime center. Use the full-color logo on light or dark backgrounds and monochrome exports when reproduction is restricted to one ink.

Keep at least half the mark width clear on each side. Do not use the mark below 16 CSS pixels, reshape it, recolor paths independently, add shadows, rotate it, place it inside a retail object, or animate it inside an app icon. The horizontal lockup is the default web navigation treatment; the stacked lockup is intended for compact square contexts.

The wordmark uses editable SVG text and can fall back to a platform geometric sans font. Platform raster exports have not been generated because Flutter and image export tooling are not available in this environment. Trademark clearance has not been performed.
